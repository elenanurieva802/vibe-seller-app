# Вайб-селлер — мини-апп

Telegram Mini App «Вайб-селлер»: ИИ-сотрудники для WB и Ozon — и школа, как ими управлять.

- `index.html` — приложение (движок + дизайн «Графит»)
- `data.json` — весь контент (уроки, тарифы, «о нас»); правки контента делаются здесь
- `theme-*.css` — альтернативные темы для предпросмотра (`index.html?theme=violet|ink`)

Публикуется через GitHub Pages, открывается кнопкой меню в боте [@vibe_sellerhelp_bot](https://t.me/vibe_sellerhelp_bot).
